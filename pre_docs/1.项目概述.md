# 1. 项目概述

## 1.1 项目名称

**MiniMax-H3 视频生成 API 服务**（目录名 `comfy`），是基于 [ComfyUI](https://github.com/comfyanonymous/ComfyUI) 与 MiniMax 自研 H3 视频扩散模型的 **多 GPU 视频生成 HTTP 网关**。

## 1.2 项目定位

它不是单纯的 ComfyUI 包装，而是一个**面向生产的视频生成后端服务**，提供：

- 统一的 HTTP 接口（自有 `/api/v1/*` + OpenAI 兼容 `/videos` 端点）
- 多 GPU 自动负载均衡（最少队列优先）
- 文生视频（T2VA）+ 图生视频（FL2VA，首帧/尾帧）+ 参考图视频（REF2VA）
- **后期音视频混流**：edge-tts 中文口播、BGM 背景音乐、静音剥离
- 任务元数据持久化（服务重启不丢失后期混流）
- 双 worker 隔离部署（独立输出/用户/数据库目录）

## 1.3 核心能力一览

| 能力 | 说明 |
|------|------|
| 文生视频 | `POST /api/v1/generate` 不传图片 → T2VA |
| 图生视频（首帧） | `first_frame` 字段 → FL2VA |
| 图生视频（首末帧） | `first_frame` + `last_frame` → 无缝转场 |
| 参考图视频（人物一致性） | OpenAI 兼容端点 `reference_images[]` → REF2VA，最多 9 张 |
| 中文人声旁白 | `voiceover` 字段 → edge-tts 合成 + ffmpeg 混流 |
| 背景音乐 | `bgm` 字段 → 自动下载/复制 + 循环 + 淡出 + 音量调节 |
| 静音模式 | `no_audio=true` → 剥掉 H3 原生音效 |
| 分辨率自适应 | 不传宽高时按图片比例适配到 768 短边、32 倍数对齐 |

## 1.5 默认部署形态

- **API 网关端口**：8000（FastAPI + uvicorn）
- **GPU 0 worker**：8188（`--cuda-device 0`）
- **GPU 1 worker**：8189（`--cuda-device 1`，独立 `--output-directory` / `--user-directory` / `--database-url`）
- **公网示例地址**：`http://117.50.216.253:8000`
- **进程守护**：tmux 会话 `comfy-multi` 或 PM2

## 1.6 典型用例

- **短视频自动化生产**：竖屏 768×1344、5–10 秒、配合中文口播脚本 → 直接产出抖音/小红书可用的成品视频
- **电商商品演示**：上传商品首图 → 自动生成多角度展示视频
- **故事板 / 分镜一致性**：上传人物定妆照 + 多个分镜关键帧 → 多镜头同一人物风格视频

## 1.7 代码组织

```
comfy/
├── api_server.py          # 主服务（FastAPI 封装 + 多 worker 调度 + 后处理）
├── client_example.py      # Python 调用示例（CLI 工具）
├── gen.sh                 # 一键运行脚本（默认读 prompt.txt）
├── start_services.sh      # tmux 双 GPU 启动脚本
├── ecosystem.config.cjs   # PM2 守护进程配置
├── prompt.txt             # 示例提示词
├── monitor.py             # 单任务耗时监控
├── bench.py               # 并发基准测试
├── test_h3.py             # 单 worker 文生视频测试
├── test_two.py            # 双 worker 并行测试 + 自动下载
├── api_state.json         # 任务元数据持久化文件
├── ComfyUI/               # ComfyUI 子模块（含自定义 H3 节点）
│   ├── comfy_extras/nodes_minimax_h3.py  # H3 节点定义
│   ├── comfy/ldm/minimax/                # 模型定义（VAE/Audio VAE/DiT）
│   ├── comfy/text_encoders/minimax.py    # Qwen3-VL 编码器
│   └── models/                           # 模型权重
├── muxed/                 # 混流后视频输出目录
├── venv/                  # Python 虚拟环境
├── logs/                  # 运行日志
└── wheels/                # 离线 pip 包
```
