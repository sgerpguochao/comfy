# 4. HTTP API 参考

API 服务监听 `:8000`，提供 **两组** 端点：

- **A 组**（原生 `/api/v1/*`）：项目自有协议，所有参数显式
- **B 组**（OpenAI 兼容 `/videos`、`/models`）：与 OpenAI Sora 等视频 API 兼容，便于上游无缝接入

两组端点内部复用同一提交/查询逻辑。

---

## A 组：原生 API

### `GET /health`

健康检查，遍历所有 worker 调 `/system_stats`。

**响应 200**：

```json
{
  "status": "ok",       // 或 "degraded"
  "workers": [
    {"worker": 0, "url": "http://127.0.0.1:8188", "ok": true},
    {"worker": 1, "url": "http://127.0.0.1:8189", "ok": true}
  ]
}
```

### `POST /api/v1/upload`

把图片上传到共享 `ComfyUI/input/`，返回裸文件名供 `first_frame` / `last_frame` 引用。**避免反复 base64 上传同一张大图**。

**请求**：`multipart/form-data`，字段名 `file`，≤30 MB。

**响应 200**：

```json
{"filename": "i2v_a1b2c3d4e5f6.png"}
```

### `POST /api/v1/generate`

提交生成任务（**异步，202**）。

**请求体**（`GenerateRequest`）：

| 字段 | 类型 | 必填 | 默认 | 范围 | 说明 |
|------|------|------|------|------|------|
| `prompt` | str | ✅ | — | — | 视频提示词 |
| `width` | int | — | 图生视频时按图自适应；文生视频时 1344 | 32-2048 | 视频宽度 |
| `height` | int | — | 同上 768 | 32-2048 | 视频高度 |
| `duration` | float | — | 5.0 | 1.0-20.0 | 时长（秒） |
| `seed` | int | — | 0 | 0..2^64-1 | 随机种子 |
| `steps` | int | — | 10 | 1-100 | 采样步数 |
| `first_frame` | str | — | — | — | 首帧引用（4 种形式） |
| `last_frame` | str | — | — | — | 尾帧引用（4 种形式） |
| `image` | str | — | — | — | 单图快捷方式（等价 `first_frame`） |
| `voiceover` | str | — | — | — | 中文口播文案，非空时自动混流 |
| `voice` | str | — | `zh-CN-XiaoxiaoNeural` | — | edge-tts 音色 ID |
| `no_audio` | bool | — | false | — | 剥掉 H3 原生音效 |
| `bgm` | str | — | — | — | BGM 路径/URL/裸文件名 |
| `bgm_volume` | float | — | 0.3 | 0.0-1.0 | BGM 相对音量 |

**`first_frame` / `last_frame` 4 种引用形式**：

1. `http(s)://...`：服务端下载
2. `data:image/png;base64,...`：base64 内嵌
3. `/api/v1/upload` 返回的裸文件名：直接使用共享 input 目录
4. 服务器本地路径（绝对或 input 目录相对）

**响应 202**：

```json
{
  "task_id": "uuid",
  "status": "queued",
  "worker": 0,                // 分发到的 worker 索引
  "frame_count": 125,
  "duration": 5.0
}
```

**响应 502**：worker 提交失败（如节点错误），`detail` 字段透传 ComfyUI 错误。

### `GET /api/v1/task/{task_id}`

轮询任务状态与产出。

**响应 200**（已派发但未完成）：

```json
{"task_id": "uuid", "status": "queued"}
```

**响应 200**（完成）：

```json
{
  "task_id": "uuid",
  "status": "success",        // 或 "error"
  "progress": null,
  "videos": ["http://host/api/v1/video/muxed_<uuid>.mp4"],
  "audio_processed": true     // 若执行了后处理
}
```

**响应 200**（失败）：

```json
{"task_id": "uuid", "status": "error", "error": "节点 X 报错：..."}
```

> `videos[0]` URL 默认指向**混流后**文件（如有口播/BGM），未混流则指向 worker 原文件（需带 `?subfolder=`）。

### `GET /api/v1/video/{filename}`

视频代理（避免外部直连 worker 端口）。支持查询参数 `subfolder`。

- `filename` 在 `_muxed` 字典中 → 直接伺服本地 muxed 文件
- 否则按 `_video_worker[filename]` 记录的 worker → 拉取 worker `/view` 输出

## B 组：OpenAI 兼容

### `GET /models`

列出可用的"模型"。

```json
{"data": [{"id": "minimax-h3", "name": "MiniMax-H3", "type": "video"}]}
```

### `POST /images/generations`

MiniMax-H3 是视频模型，**不支持**。返回 400。

### `POST /videos` / `POST /videos/generations`

OpenAI 兼容的视频生成端点。

**请求体**（兼容 OpenAI 风格）：

```json
{
  "prompt": "竖屏 9:16，年轻上班族...",
  "duration": 5.0,
  "seed": 42,
  "steps": 10,
  "resolution": "1080p",      // 或 "720p" / "480p"；可省略
  "width": 768, "height": 1344,  // 优先于 resolution
  "input": ["https://.../a.png", "https://.../b.png"],  // OpenAI 风格首/尾帧
  "first_frame": "...", "last_frame": "...", "image": "...",
  "reference_images": ["https://.../person.jpg", "https://.../scene1.jpg"],
  "ref_image_size": "max",   // 或 "match"
  "voiceover": "...",
  "voice": "zh-CN-XiaoxiaoNeural",
  "no_audio": false,
  "bgm": "...",
  "bgm_volume": 0.3
}
```

**关键差异**：

- `input[]` 数组：第 1 个为首帧，第 2 个为尾帧；支持字符串或 `{type:image_url, image_url:{url}}` 对象
- `reference_images[]`（≤9 张）：人物定妆照 + 分镜关键帧，全程参与 conditioning（REF2VA 路径）
- prompt 中 `@ImageN` / `@图片N` 引用**自动重写**为 `<Picture N>`（与 Seedance 风格一致）
- `resolution` → `1080p/720p/480p` 经 `RESOLUTION_MAP` 转 `(1920,1080)/(1280,720)/(854,480)`，再由 `adapt_canvas_size` 对齐到 32 倍数
- 传 `reference_images` → 走 `_submit_ref2v_job`；否则走 `_submit_job`

**响应 200**：

```json
{"id": "<task_id>", "status": "queued"}
```

### `GET /videos/{task_id}`

OpenAI 风格的任务状态查询。

**响应**：

```json
{
  "id": "<task_id>",
  "status": "completed",       // queued / processing / completed / failed
  "data": [{"url": "http://host/api/v1/video/muxed_xxx.mp4"}]
}
```

### `GET /videos/{task_id}/content`

视频下载端点：返回 302 重定向到实际视频 URL（便于 OpenAI 兼容客户端用 `redirect=True` 直接拿到二进制）。

## 错误码

| 状态码 | 含义 |
|--------|------|
| 200 | 成功（含状态查询） |
| 202 | 任务已接受（异步） |
| 400 | 参数错误（图片引用无法识别、超过 30 MB、缺 `prompt` 等） |
| 404 | 任务不存在 / 视频未就绪 |
| 502 | 透传 ComfyUI 错误（worker 提交失败、ComfyUI 节点错误） |

## 速率与并发

API 服务**未实现限流与鉴权**。生产部署建议：

- 前置 nginx/OpenResty：按 IP/QPS 限流
- 客户端：`async` 池 + semaphore 控制并发提交数（建议 ≤ GPU 数 × 2）

## CORS

`CORSMiddleware(allow_origins=["*"], allow_methods=["*"], allow_headers=["*"])` —— 默认全开，便于浏览器侧调试。
