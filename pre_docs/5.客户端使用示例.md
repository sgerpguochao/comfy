# 5. 客户端使用示例

## 5.1 `client_example.py` —— Python CLI 一体化工具

最简单的入口，自动处理图片 base64 编码、提交、轮询。

### 5.1.1 文生视频（最简）

```bash
python client_example.py "海浪拍打礁石，清晨金色阳光，航拍，写实风格，无文字"
```

默认 1344×768、5 秒、seed=42、steps=20。

### 5.1.2 显式指定宽高/时长

```bash
# 竖屏 768x1344，5 秒
python client_example.py "让这只猫动起来" 768 1344 5

# 横屏 1344x768，10 秒
python client_example.py "无人机航拍城市天际线" 1344 768 10
```

### 5.1.3 图生视频（首帧）

```bash
python client_example.py "让这只猫动起来" --first cat.png
```

不传 `width/height` 时，服务端按图片比例**自动适配到 768 短边、32 倍数对齐**。

### 5.1.4 图生视频（首末帧，无缝转场）

```bash
python client_example.py "无缝转场" --first a.png --last b.png 768 1344 5
```

### 5.1.5 图生视频 + 中文口播（典型短视频）

```bash
python client_example.py "矿泉水瓶滑落" \
  --first a.png --last b.png \
  --voiceover "清凉一夏，就喝迎驾山泉！" \
  --voice zh-CN-YunxiNeural
```

### 5.1.6 静音模式

```bash
python client_example.py "海浪拍打礁石" --no-audio
```

剥掉 H3 原生音效（仅留画面）。

### 5.1.7 指定服务器

```bash
python client_example.py "..." http://117.50.216.253:8000
```

URL 参数作为最后一个非数值参数传入。

### 5.1.8 关键代码片段

```35:41:comfy/client_example.py
def file_to_data_uri(path: str) -> str:
    ext = path.rsplit(".", 1)[-1].lower() if "." in path else "png"
    mime = {"jpg": "image/jpeg", "jpeg": "image/jpeg",
            "png": "image/png", "webp": "image/webp"}.get(ext, "image/png")
    with open(path, "rb") as f:
        return f"data:{mime};base64," + base64.b64encode(f.read()).decode()
```

## 5.2 `curl` 速查

### 文生视频

```bash
curl -X POST http://127.0.0.1:8000/api/v1/generate \
  -H "Content-Type: application/json" \
  -d '{
    "prompt": "海浪拍打礁石，清晨金色阳光，航拍",
    "width": 1344, "height": 768, "duration": 5,
    "seed": 42, "steps": 10
  }'
```

返回：`{"task_id": "...", "status": "queued", "worker": 0, ...}`

### 轮询

```bash
curl http://127.0.0.1:8000/api/v1/task/<task_id>
```

### 图生视频（base64 内嵌）

```bash
IMG=$(base64 -w0 cat.png)
curl -X POST http://127.0.0.1:8000/api/v1/generate \
  -H "Content-Type: application/json" \
  -d "{
    \"prompt\": \"让这只猫动起来\",
    \"first_frame\": \"data:image/png;base64,$IMG\",
    \"duration\": 5
  }"
```

### 图生视频 + 口播

```bash
curl -X POST http://127.0.0.1:8000/api/v1/generate \
  -H "Content-Type: application/json" \
  -d '{
    "prompt": "矿泉水瓶滑落",
    "first_frame": "https://example.com/a.png",
    "last_frame": "https://example.com/b.png",
    "voiceover": "清凉一夏，就喝迎驾山泉！",
    "voice": "zh-CN-YunxiNeural",
    "duration": 5
  }'
```

### OpenAI 兼容端点

```bash
curl -X POST http://127.0.0.1:8000/videos \
  -H "Content-Type: application/json" \
  -d '{
    "prompt": "竖屏 9:16，...",
    "resolution": "1080p",
    "duration": 5,
    "reference_images": ["https://example.com/person.jpg"]
  }'
```

返回 `{"id": "..."}`；轮询 `GET /videos/<id>`。

## 5.3 编程式 Python（推荐用于生产）

```python
import asyncio
import aiohttp


async def gen_one(prompt, **kw):
    async with aiohttp.ClientSession() as s:
        async with s.post("http://127.0.0.1:8000/api/v1/generate",
                          json={"prompt": prompt, **kw}) as r:
            data = await r.json()
            task_id = data["task_id"]

        # 轮询
        while True:
            await asyncio.sleep(15)
            async with s.get(f"http://127.0.0.1:8000/api/v1/task/{task_id}") as r:
                t = await r.json()
                if t["status"] in ("success", "error"):
                    return t


async def main():
    results = await asyncio.gather(
        gen_one("海浪拍打礁石", width=1344, height=768, duration=5),
        gen_one("猫在窗台晒太阳", width=768, height=1344, duration=5),
    )
    for r in results:
        print(r)


asyncio.run(main())
```

## 5.5 提示词约定

`prompt.txt` 示例（短视频旁白 + 画面描述三段式）：

```
旁白：打工人必备！3个AI神器，小白也能用
画面：竖屏9:16，年轻上班族在明亮工位上对着手机惊讶捂嘴，...
旁白：写文案、做PPT，AI三分钟搞定
画面：竖屏9:16，笔记本电脑屏幕特写，...
旁白：最后一个更绝，会议纪要自动生成
画面：竖屏9:16，手机录音波形图逐渐变成整齐排列的文字纪要，...
```

**约定**：每段 `"旁白：...画面：..."` 描述一组镜头，模型自动生成对应的画面+音效。

## 5.6 图片上传复用（避免 base64）

```bash
# 上传一次，返回文件名
curl -X POST http://127.0.0.1:8000/api/v1/upload \
  -F "file=@cat.png"
# {"filename": "i2v_a1b2c3d4e5f6.png"}

# 后续任务直接引用
curl -X POST http://127.0.0.1:8000/api/v1/generate \
  -H "Content-Type: application/json" \
  -d '{"prompt": "...", "first_frame": "i2v_a1b2c3d4e5f6.png", "duration": 5}'
```

适合**同一张参考图**被多次使用（如商品展示多角度）。
