# 7. 模型与节点细节

## 7.1 模型层（H3 packed-DiT）

H3 是一个 **AV 双流 packed-DiT**：

- **视频 latent 形状**：`[B, 24, T, H/16, W/16]`（24 通道、T 个时间步）
- **音频 latent 形状**：`[B, 32, 2, T40]`（32 通道、立体声、40 fps 对齐）
- **采样**：在扁平的 pack 上运行任意常规 sampler；音频流的 sigma schedule 由模型**内部偏移**处理
- **conditioning**：Qwen3-VL-32B hidden states（带 per-token modality tags）+ 关键帧/参考图 latents（每步重新注入，不参与去噪）

源码入口：`ComfyUI/comfy_extras/nodes_minimax_h3.py`

## 7.3 帧数对齐

```33:46:comfy/ComfyUI/comfy_extras/nodes_minimax_h3.py
def align_frame_count(n):
    while n % 17 != 5:
        n += 1
    return n

def video_latent_t(frame_count):
    return 2 if frame_count <= 5 else ((frame_count - 5) // 17) * 5 + 2

def temporal_shape(length):
    frame_count = align_frame_count(max(5, length))
    duration = frame_count / FPS
    return frame_count, video_latent_t(frame_count), round(duration * AUDIO_LATENT_FPS)
```

- **帧数对齐到 `17k+5`**：H3 模型的 latent 时间维必须满足
- `duration × 24` 后向上对齐到 `17k+5`
- 例如 5 秒 → 125 帧（5+17×7）；10 秒 → 245 帧（5+17×14）

API 服务对应实现：

```59:62:comfy/api_server.py
def frame_count_for_duration(duration: float) -> int:
    """duration(秒) -> 帧数，对齐到模型 17k+5 帧网格。"""
    n = max(5, round(duration * DEFAULT_FPS))
    return n + (5 - n % 17) % 17
```

## 7.4 画布自适应

```49:60:comfy/ComfyUI/comfy_extras/nodes_minimax_h3.py
def adapt_canvas(width, height):
    """768-short-edge canvas with 768*1344 area cap, per-axis round to 32."""
    ratio = width / height
    if ratio >= 1.0:
        nom_w, nom_h = BASE_SHORT_EDGE * ratio, BASE_SHORT_EDGE
    else:
        nom_w, nom_h = BASE_SHORT_EDGE, BASE_SHORT_EDGE / ratio
    if nom_w * nom_h > MAX_PIXELS:
        s = math.sqrt(MAX_PIXELS / (nom_w * nom_h))
        nom_w, nom_h = nom_w * s, nom_h * s
    return (max(CANVAS_MULTIPLE, round(nom_w / CANVAS_MULTIPLE) * CANVAS_MULTIPLE),
            max(CANVAS_MULTIPLE, round(nom_h / CANVAS_MULTIPLE) * CANVAS_MULTIPLE))
```

**约束**：

1. **短边 768**：H3 模型的最优输入分辨率
2. **面积 ≤ 768×1344**：显存上限
3. **每边对齐到 32 倍数**：latent patch size = 2，必须能被 32 整除

API 服务对应实现：

```65:75:comfy/api_server.py
def adapt_canvas_size(width: int, height: int) -> tuple:
    """短边 768、面积上限 768*1344、逐轴对齐 32 的画布（与 H3 节点 adapt_canvas 一致）。"""
    ratio = width / height
    if ratio >= 1.0:
        nom_w, nom_h = 768 * ratio, 768
    else:
        nom_w, nom_h = 768, 768 / ratio
    if nom_w * nom_h > 768 * 1344:
        s = math.sqrt(768 * 1344 / (nom_w * nom_h))
        nom_w, nom_h = nom_w * s, nom_h * s
    return max(32, round(nom_w / 32) * 32), max(32, round(nom_h / 32) * 32)
```

> ⚠️ 标准 1080p / 720p / 480p 不满足 32 倍数（如 1080/32=33.75），OpenAI 兼容端点的 `resolution` 字段会自动经过 `adapt_canvas_size` 对齐。

## 7.5 Latent AV 节点

### EmptyMiniMaxH3LatentAV（节点 79-）

```70:76:comfy/ComfyUI/comfy_extras/nodes_minimax_h3.py
def _empty_av_latent(width, height, length, batch_size=1):
    frame_count, latent_t, audio_t = temporal_shape(length)
    video = torch.zeros([batch_size, 24, latent_t, height // 16, width // 16],
                        device=comfy.model_management.intermediate_device())
    audio = torch.zeros([batch_size, 32, 2, audio_t],
                        device=comfy.model_management.intermediate_device())
    return {"samples": comfy.nested_tensor.NestedTensor((video, audio))}, frame_count
```

返回 `NestedTensor((video, audio))` —— H3 的核心数据结构，把视频和音频 latent 打包成一对。

## 7.7 两条路径的差别

### T2VA / FL2VA（`MiniMaxH3ImageToVideo`）

```126:128:comfy/api_server.py
"5": {"class_type": "MiniMaxH3ImageToVideo",
      "inputs": {"clip": ["2", 0], "vae": ["3", 0], "prompt": prompt,
                 "width": width, "height": height, "length": length}},
```

- 不传图 → 文生视频
- 传 `first_frame` → 图生视频（单图）
- 传 `first_frame` + `last_frame` → 首末帧驱动（图生视频变体）

### REF2VA（`MiniMaxH3ReferenceToVideo`）

```178:183:comfy/api_server.py
"5": {"class_type": "MiniMaxH3ReferenceToVideo",
      "inputs": {"clip": ["2", 0], "vae": ["3", 0], "audio_vae": ["4", 0],
                 "prompt": prompt, "width": width, "height": height,
                 "length": length, "ref_image_size": ref_image_size,
                 "ref_images": {f"ref_image_{i}": [str(15 + i), 0]
                                for i in range(len(ref_images))}}},
```

- **关键差异**：`ref_images` 通过 conditioning 注入，每步重新注入（不参与去噪）
- `ref_image_size`：`max`（2048 短边，保真度高） / `match`（按画布面积等比缩放，更快）
- 节点上限 9 张，超出丢弃
- prompt 中的 `<Picture N>` 占位符对应第 N 张图

## 7.8 量化策略

模型名中的 `int8_convrot` 含义：

- **INT8 量化**：权重/激活 int8，节省显存与算力
- **convrot**：旋转量化（rotation-based quantization），对卷积/DiT 块做 Hadamard 旋转，缓解 INT8 精度损失

源码路径：`ComfyUI/comfy/ldm/minimax/model.py`（DiT 定义）、`ComfyUI/comfy/ldm/minimax/vae.py`（视频 VAE）、`ComfyUI/comfy/ldm/minimax/audio_vae.py`（音频 VAE）、`ComfyUI/comfy/text_encoders/minimax.py`（Qwen3-VL 编码器）。

## 7.9 加速开关

`--fast autotune cublas_ops`：

- **autotune**：首次运行尝试多种 kernel 实现，选最快的缓存
- **cublas_ops**：启用 cuBLAS 算子（含 int8 GEMM），显著加速矩阵乘

